# 📊 Retail Demand Forecasting Executive Dashboard

A Power BI dashboard designed to transform machine learning forecast results into a practical, decision-support tool for retail inventory management.

---

## 📌 Overview

This dashboard visualizes the output of a demand forecasting pipeline and enables store managers and supply chain analysts to monitor forecast accuracy, identify inventory risks, and support data-driven replenishment decisions — all from a single view.

| Metric | Value |
|---|---|
| Total Actual Sales | 32.72M |
| Total Forecast Sales | 32.60M |
| Forecast Error | 0.12M |
| Overall Accuracy | **99.63%** |

> Analysis period: Jan 2012 – Oct 2012 (monthly granularity)

---

## 🗂️ Data Source

The dashboard reads directly from **`forecast_result.csv`**, the output file generated by the upstream forecasting pipeline.

```
forecasting-pipeline/
│
├── forecast_result.csv          ← Dashboard input source
└── retail_dashboard.pbix        ← Power BI report file
```

**Key columns expected in `forecast_result.csv`:**

| Column | Description |
|---|---|
| `date` | Sales date (monthly) |
| `store` | Store identifier |
| `product` | Product identifier |
| `actual_sales` | Recorded sales volume |
| `forecast_sales` | Model-predicted sales volume |
| `forecast_error` | Difference: actual − forecast |
| `accuracy` | Forecast accuracy (%) per product |

## 🖥️ Dashboard Components

### 1. KPI Cards (Top Row)
Four headline metrics provide an at-a-glance summary of overall forecasting health across all stores and products.

### 2. Monthly Sales Performance Chart
A dual-line time series comparing **Total Actual Sales** (solid blue) against **Total Forecast Sales** (dashed red) from January to October 2012. The two lines track closely throughout, demonstrating the model's ability to capture seasonal fluctuations and sales volatility effectively.

### 3. Detailed Performance Table (by Store / Product)
A sortable table listing per-product **Accuracy (%)** and **Forecast Error**, color-coded by risk level (red = low accuracy). This table helps managers quickly surface problematic products that require attention.

**How to interpret Forecast Error:**

| Error Direction | Interpretation | Inventory Risk |
|---|---|---|
| Large **positive** error | Model over-predicted demand | ⚠️ Overstock risk |
| Large **negative** error | Model under-predicted demand | ⚠️ Stockout risk |
| Near zero | Well-calibrated forecast | ✅ Low risk |

> **Example from current data:** Product 6 (Accuracy: 82.50%, Error: −17,454) signals a potential stockout risk. Product 3 (Accuracy: 90.38%, Error: +42,329) signals overstock risk.

### 4. Filters / Slicers
- **Select Store** — Filter all visuals by a specific store (currently showing Store 45)
- **Analysis Period** — Limit the view to a specific time window (default: All)

## 🚀 Getting Started

### Prerequisites
- Power BI Desktop (latest version recommended)
- `forecast_result.csv` generated by the forecasting pipeline

### Steps

1. **Clone this repository**
   ```bash
   git clone https://github.com/your-username/retail-demand-forecasting.git
   cd retail-demand-forecasting
   ```

2. **Run the forecasting pipeline** to generate `forecast_result.csv`  
   *(See the pipeline README for instructions)*

3. **Open the dashboard**  
   Launch `retail_dashboard.pbix` in Power BI Desktop.

4. **Refresh the data source**  
   Go to **Home → Transform Data → Data Source Settings** and point the source to your local `forecast_result.csv` path, then click **Refresh**.

5. **Use the slicers** to filter by store or time period as needed.
