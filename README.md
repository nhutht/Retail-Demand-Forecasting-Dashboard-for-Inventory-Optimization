# Retail Demand Forecasting Executive Dashboard

## Overview
This project presents a retail demand forecasting and sales performance dashboard developed using Power BI. The dashboard is designed to support business monitoring, inventory planning, and performance evaluation through interactive visual analytics and forecasting metrics.

The report enables users to compare actual sales and forecasted sales, evaluate forecast accuracy, and identify operational insights across products and stores.

---

## Objectives
- Monitor retail sales performance over time
- Compare forecasted demand against actual sales
- Evaluate forecasting accuracy and forecast error
- Support inventory and operational planning decisions
- Improve visibility of business KPIs through interactive dashboards

---

## Key Features
- Interactive Power BI dashboard
- Actual vs Forecast Sales comparison
- Forecast Accuracy and Forecast Error tracking
- Store and product performance analysis
- KPI summary cards for executive reporting
- Dynamic filtering by store and analysis period

---

## Dashboard Metrics
- Total Forecast Sales
- Total Actual Sales
- Forecast Accuracy
- Forecast Error
- Monthly Sales Performance Trends
- Product-level Accuracy Analysis

---

## Tools & Technologies
- Power BI
- Python
- SQL
- Excel
- Data Cleaning & Validation
- Forecasting Analysis

---

## Business Value
This dashboard helps transform raw retail data into actionable business insights by:
- Supporting demand planning decisions
- Improving visibility into sales performance
- Identifying forecasting gaps and operational inefficiencies
- Enhancing reporting efficiency for stakeholders
