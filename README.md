##  Overview

This project presents a retail demand forecasting and sales performance dashboard developed using Power BI. The dashboard was developed to transform the forecasting results into a practical decision-support tool, enabling store managers and supply chain analysts to monitor forecast accuracy, identify inventory risks, and support data-driven replenishment decisions — all from a single view.

The dashboard uses **`forecast_result.csv`** generated by the forecasting pipeline as its primary input source.

##  Dashboard Components

### 1. KPI Cards — Top Row
Four headline metrics provide an at-a-glance summary of overall forecasting health across all stores and products.

### 2. Monthly Sales Performance Chart
A dual-line time series comparing **Total Actual Sales** (solid blue) against **Total Forecast Sales** (dashed red). The two lines remain very close throughout the period, showing that the model can effectively capture sales fluctuations and seasonal patterns.

### 3. Detailed Performance Table — By Store / Product
A sortable table listing per-product **Accuracy (%)** and **Forecast Error**, color-coded by risk level (red = low accuracy). This table helps managers quickly identify forecasting risks by department.

**How to interpret Forecast Error:**

| Error Direction | Interpretation | Inventory Risk |
|---|---|---|
| Large **positive** error | Model over-predicted demand | ⚠️ Overstock risk |
| Large **negative** error | Model under-predicted demand | ⚠️ Stockout risk |
| Near zero | Well-calibrated forecast | ✅ Low risk |

> **Live examples:** Product 6 (Accuracy: 82.50%, Error: −17,454) → potential **stockout** risk. Product 3 (Accuracy: 90.38%, Error: +42,329) → potential **overstock** risk.

### 4. Filters / Slicers
| Slicer | Description |
|---|---|
| **Select Store** | Filter all visuals to a specific store |
| **Analysis Period** | Restrict the view to a custom date range (default: All) |

##  Getting Started

### Prerequisites
- Power BI Desktop (latest version recommended)
- `forecast_result_stage9.csv` generated by the forecasting pipeline

### Steps

1. **Clone this repository**
   ```bash
   git clone https://github.com/your-username/retail-demand-forecasting.git
   cd retail-demand-forecasting
   ```

2. **Run the forecasting pipeline** to generate `forecast_result_stage9.csv`
   ```bash
   cd pipeline
   pip install -r requirements.txt
   python predict.py
   ```

3. **Open the dashboard**
   Launch `thesis.pbix` in Power BI Desktop.

4. **Refresh the data source**
   Go to **Home → Transform Data → Data Source Settings**, point the source to your local `forecast_result.csv`, then click **Refresh**.

5. **Explore the dashboard**
   Use the **Select Store** and **Analysis Period** slicers to filter by store or time window.
